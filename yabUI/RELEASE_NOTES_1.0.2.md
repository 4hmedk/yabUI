# yabUI 1.0.2

This release turns the menu-bar item into a compact yabUI surface:

- native window-style popover instead of a plain rendered command list
- prominent play/pause-style start/stop control and restart action
- live unified window map with app icons and space labels
- click a tile to focus its real Yabai window
- drag a tile onto another window to swap or split it
- drag a tile into another space region to move it there
- quick balance, float/tile, zoom, and rotate controls remain available
