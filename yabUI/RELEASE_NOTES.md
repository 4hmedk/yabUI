# yabUI 1.0.0

The first yabUI release adds a native GUI layer to the Yabai fork:

- compact liquid-glass workspace overview
- live display, space, and window visualization
- drag-and-drop space reordering and window placement
- automatic layout rebalancing after moves
- service start, stop, restart, and status controls
- menu-bar controls for common actions
- bundled universal Yabai runtime for simpler installation

The release app is distributed separately from the source tree as a `.dmg`
and `.zip` asset.
